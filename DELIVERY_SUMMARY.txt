HOW TO USE THE PROJECT
================================================================================

For Users:
1. Install: Download and run the MSI installer
2. Setup: Configure API key in settings
3. Use: Press spacebar to record, wait for AI response

For Developers:
1. Setup: npm install (requires Node.js)
2. Dev: npm run dev (start development server)
3. Build: npm run build (create production build)

For Deployment:
1. Setup: Install Rust and Windows SDK
2. Build: npm run build:windows (create MSI)
3. Deploy: Distribute the .msi file

================================================================================
API CONFIGURATION
================================================================================

Google Gemini (Recommended - Free):
1. Visit https://aistudio.google.com/apikey
2. Click "Create API Key"
3. Paste in app settings

OpenAI (Alternative):
1. Visit https://platform.openai.com/api-keys
2. Create new secret key
3. Paste in app settings

Both APIs are supported and can be switched via settings modal.
